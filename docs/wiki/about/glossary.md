# Glossary

| Term | Meaning |
|---|---|
| Landmark | Estimated location and visibility of a body joint |
| Threshold | Boundary that a measured angle or displacement must cross |
| Legacy preset | Shipped activity settings used without an activated movement version |
| Candidate | Immutable proposed movement rules saved for evaluation |
| Held-out session | Recording session kept separate from calibration |
| Activation | Selecting an evaluated version for later workouts |
| Pinned version | The rules fixed for one running workout |
| Honor mode | Completion recorded without camera verification |
| Publication queue | Local records waiting for acknowledgement from the hub |

See [detection](../concepts/detection.md) for examples.
