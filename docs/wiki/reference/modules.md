# Module map

| Directory | Purpose |
|---|---|
| `app/src` | React desktop views and interaction |
| `app/src-tauri/src` | Native commands, windows, resources and hub integration |
| `app/src-tauri/engine` | Session, timer, daily plan and local history |
| `app/src-tauri/hub-client` | Hub client, process supervisor and publication queue |
| `vision/src/reps_vision` | Pose model, legacy activities and versioned movement detector |
| `companion` | Reps companion pages |
| `scripts` | Packaging, replay and verification tools |

See [architecture](../../architecture/index.md) for source links and design coverage.
