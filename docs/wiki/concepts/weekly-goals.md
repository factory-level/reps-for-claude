# Daily routine

The current desktop prescribes a daily routine, one set per break. The bundled
routine contains lifts, jump-rope rounds, and timed stretches. Completion is
restored for the current day and resets for a new date.

Use `routine.json` in the app data directory to customize it, then restart.
The [configuration guide](../reference/config.md) shows the location and format.
Custom lift IDs must match an active, evaluated Studio movement. Existing shipped
lifts can use their legacy preset until a version is activated.

The older weekly-goals Python configuration is superseded by this daily plan.
